# PopSGX-uffd-monitor

PopSGX-uffd-monitor is a framework designed to facilitate access to remote hardware trusted execution environments (TEEs) for any non-TEE devices, including low-end embedded devices. 
It enables transparent integration with hardware enclaves, such as Intel SGX, allowing developers to leverage the security benefits of TEEs 

Kindly refer to our [wiki](https://github.com/ssrg-vt/PopSGX-uffd-monitor/wiki) for a tutorial on how to leverage PopSGX for remote enclaves.
